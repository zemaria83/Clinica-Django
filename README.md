# Clinica Django

## Descricao

Aplicação web desenvolvida com Django no âmbito do projeto final da disciplina de **Administração de Sistemas II**, do curso **CTeSP de Cibersegurança** do **ISTEC — Instituto SUperior de Tecnologias Avançadas**, Porto.

## Tecnologias utilizadas

- Python 3 + Django 5.2
- MySQL (via Docker)
- Docker + Docker Compose
- Gunicorn
- WhiteNoise
- Django Jazzmin

## Como executar

```bash
docker compose up --build
```

Aceder em: http://localhost:8000  
Admin em: http://localhost:8000/admin
